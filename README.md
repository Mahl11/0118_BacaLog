## Ringkasan Proyek

**BacaLog** adalah aplikasi Android berbasis Kotlin Jetpack Compose (Material 3) yang dirancang untuk membantu mahasiswa dan pembelajar mandiri mencatat bahan bacaan (buku referensi kuliah, jurnal, dan modul belajar), memantau log progres harian (halaman buku yang dicapai dan ringkasan refleksi materi), serta menetapkan target baca periodik secara terukur.

Aplikasi ini menggunakan arsitektur **MVVM (Model-View-ViewModel)** dengan **Navigation Compose**, terhubung ke database **MySQL** melalui **REST API (JSON)** dengan autentikasi **JWT (Access & Refresh Token)**, mengelola **4 entitas utama berelasi**, menyediakan **5 modul fitur CRUDS penuh**, serta mendukung pencadangan dan pembacaan laporan belajar ke file lokal (`.txt`).
